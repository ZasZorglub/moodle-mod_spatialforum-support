# Support and issue reporting

The release candidate is intended for controlled evaluation. Do not include passwords, session keys, student names, course exports or personal data in a public report.

Public issue tracker: https://github.com/ZasZorglub/moodle-mod_spatialforum-support/issues

Include the plugin version, Moodle version, PHP/database versions, browser, numbered reproduction steps, expected behaviour and actual behaviour. Use synthetic English examples and redact screenshots. Report suspected security issues privately to the maintainer through an existing private support channel; do not publish exploit details or personal data.

There is no guaranteed response time or service-level agreement for this release candidate.
