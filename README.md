# Samtalespor support

Samtalespor is a Moodle activity for threaded conversations shown as a branching map. Open posts in place, reply to a whole post or selected passages, and include Moodle-managed images, audio and video.

**Status:** 0.6.1-rc.1 is a release candidate, not a Marketplace-approved or broadly validated stable release.

- [User guide](USER-GUIDE.md)
- [Report a bug or suggest an improvement](https://github.com/ZasZorglub/moodle-mod_spatialforum-support/issues)
- [Support and reporting policy](SUPPORT.md)

This public repository contains documentation and an issue tracker. Plugin source is maintained separately. Do not post student data, passwords, session keys or unredacted course screenshots.
